About Library

The Amrita Vishwa Vidyapeetham’s Amaravati campus library, which inaugurated to the public in 2022, acts as a knowledge resource centre by containing hybrid resources. It is a Knowledge Resource Centre and supports the teaching and learning activities of all the Students, Research Scholars, Faculty Members and all other staff members in this campus.

The library includes Prescribed Textbooks, Reference books, Print Journals, Electronic books, Electronic journals, Technical magazines, General magazines, Dailies, CD’s & DVD’s, Course materials and Faculty publications etc., It follows the Universal Decimal Classification (UDC) Scheme for arrangement of books.

The Library is automated with KOHA, an integrated Library Management Software with advanced search options. This Integrated Library Management System offers fastest, easiest, most efficient way to track, locate, transaction and manage library materials. The OPAC (Online Public Access Catalogue) provides easy access to the database of books, journals, project reports and electronic resources. Users can search all materials in the library collection, including books on engineering and management, reference books, gratis books, periodicals, CD/DVD details, etc., using the OPAC (Online Public Access Catalogue).
